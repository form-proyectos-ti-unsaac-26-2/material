## Fundamento teórico

## 1. Introducción a los Fundamentos de la Informática

- **Computación** : Ciencia que estudia el procesamiento de información con computadoras siguiendo instrucciones precisas.

- **Algoritmo** : Conjunto de pasos ordenados y finitos para resolver un problema o realizar una tarea. En Google Colab, los algoritmos se escriben en Python, siguiendo una sintaxis clara y estructurada.

   - **Ejemplos** : Suma de dos números, cálculo del promedio, entre otros, etc.

- **Representación de Datos:**

   - **Datos** : Información almacenada y procesada por una computadora, como números o texto.

   - **Representación** : En Python, los datos se guardan en variables, utilizando tipos de datos como enteros, flotantes y cadenas.

## 2. Conceptos Básicos de Programación

- **Lenguajes de Programación:** Lenguajes formales que especifican instrucciones para que una computadora ejecute tareas. En Google Colab, usamos Python, un lenguaje popular y versátil.

   - **Tipos** : Python es un lenguaje estructurado y orientado a objetos, lo que lo convierte en una excelente herramienta tanto para principiantes como para usuarios avanzados.

- **Sintaxis** : Conjunto de reglas que determinan cómo escribir correctamente las instrucciones. En Python, se sigue una sintaxis clara basada en indentaciones.

- **Semántica** : Significado de las instrucciones; el programa debe ser lógicamente coherente, además de sintácticamente correcto.

## 3. Estructuras Secuenciales

**Fundamentos Teóricos:**

- **Estructura Secuencial:** Estructura donde las instrucciones se ejecutan en orden, una tras otra. Es el control de flujo más simple en Python.

   - **Características** : Ejecución lineal, donde cada paso depende del anterior. Ejemplos: operaciones aritméticas, asignaciones y entrada/salida de datos.

- **Diagrama de Flujo:** Representación gráfica de algoritmos usando formas como rectángulos (procesos) y rombos (decisiones) para mostrar el flujo de control.

- **Aplicación en Google Colab** : Aunque no incluye herramientas nativas para diagramas de flujo, es útil planificar la lógica de los algoritmos antes de programar. Los diagramas ayudan a visualizar el flujo secuencial de las instrucciones.

## 4. Introducción a las Funciones en Programación

## Fundamentos Teóricos:

- **Funciones:** Bloques de código que realizan una tarea específica y devuelven un valor, promoviendo la modularidad y reutilización. En Python, las funciones se definen utilizando la palabra clave def.

- **Procedimientos:** Similar a las funciones, pero no devuelven valor. Se usan para ejecutar tareas sin generar un resultado.

- **Parámetros:** Valores que se pasan a funciones o procedimientos para operar.

- **Valores de Retorno:** Resultado que una función devuelve para ser usado en otras partes del código.

## 5. Manejo de Datos en Programación

## Fundamentos Teóricos:

- **Variables:** Espacios en memoria que almacenan datos cambiantes. En Python, las variables se definen de manera implícita sin declarar su tipo, pero pueden almacenar diferentes tipos de datos.

- **Tipos de Datos:** Categorías de datos que una variable puede contener, como enteros (int), reales (float) y cadenas (str). Python maneja tipos de datos básicos y permite operaciones simples.

- **Operaciones Aritméticas:** Suma, resta, multiplicación y división se realizan utilizando operadores matemáticos (+, -, *, /).

- **Operaciones Lógicas:** Comparaciones y operaciones booleanas (<, >, ==, and, or) son esenciales para el control del flujo y manejo de datos.
