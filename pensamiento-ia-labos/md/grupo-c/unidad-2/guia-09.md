## Fundamento teórico

## 1. Introducción a los Fundamentos de la Informática

- **Computación** : Ciencia que estudia el procesamiento de información con computadoras siguiendo instrucciones precisas.

- **Algoritmo** : Conjunto de pasos ordenados y finitos para resolver un problema o realizar una tarea. En PSeInt, se usa pseudocódigo para expresar algoritmos de forma clara. `o` **Ejemplos** : Suma de dos números, cálculo del promedio, entre otros, etc.

- **Representación de Datos:**

   - **Datos** : Información almacenada y procesada por una computadora, como números o texto.

   - **Representación** : Forma en que los datos se guardan en la memoria, usando variables y tipos de datos. En PSeInt, se manipulan mediante variables y operaciones básicas.

## 2. Conceptos Básicos de Programación

- **Lenguajes de Programación:** Lenguajes formales que especifican instrucciones para que una computadora ejecute tareas. PSeInt usa pseudocódigo, una representación simple y comprensible de algoritmos.

   - **Tipos** : Lenguajes estructurados, orientados a objetos y funcionales. PSeInt se enfoca en un lenguaje sencillo para principiantes.

- **Sintaxis** : Conjunto de reglas que determinan cómo escribir correctamente las instrucciones. En PSeInt, se sigue la sintaxis del pseudocódigo.

- **Semántica** : Significado de las instrucciones; el programa debe ser lógicamente coherente, además de sintácticamente correcto.

## 3. Estructuras Secuenciales

## Fundamentos Teóricos:

- **Estructura Secuencial:** Estructura donde las instrucciones se ejecutan en orden, una tras otra. Es el control de flujo más simple.

   - **Características** : Ejecución lineal, donde cada paso depende del anterior. Ejemplos: operaciones aritméticas, asignaciones y entrada/salida de datos.

- **Diagrama de Flujo:** Representación gráfica de algoritmos usando formas como rectángulos (procesos) y rombos (decisiones) para mostrar el flujo de control.

- **Aplicación en PSeInt** : Aunque PSeInt usa pseudocódigo, los diagramas ayudan a planificar la lógica antes de programar.

## 4. Introducción a las Funciones en Programación

## Fundamentos Teóricos:

- **Funciones:** Bloques de código que realizan una tarea específica y devuelven un valor, promoviendo la modularidad y reutilización. En PSeInt, se definen y llaman en el pseudocódigo.

- **Procedimientos:** Similar a las funciones, pero no devuelven valor. Se usan para ejecutar tareas sin generar un resultado.

- **Parámetros:** Valores que se pasan a funciones o procedimientos para operar. En PSeInt, se definen en la cabecera.

- **Valores de Retorno:** Resultado que una función devuelve para ser usado en otras partes del código.

## 5. Manejo de Datos en Programación

## Fundamentos Teóricos:

- **Variables:** Espacios en memoria que almacenan datos cambiantes. En PSeInt, se definen para manipular información.

- **Tipos de Datos:** Categorías de datos que una variable puede contener, como enteros, reales y cadenas. PSeInt maneja tipos básicos y permite operaciones simples.

- **Operaciones Aritméticas:** Suma, resta, multiplicación y división, realizadas con operadores matemáticos en PSeInt.

- **Operaciones Lógicas:** Comparaciones y operaciones booleanas, esenciales para el control del flujo y manejo de datos.

## PSeInt como Herramienta

## Fundamentos Teóricos:

- **PSeInt:** Herramienta de programación para principiantes que permite escribir y simular algoritmos en pseudocódigo, facilitando el aprendizaje sin preocuparse por la sintaxis de lenguajes formales.

   - **Funciones:** Permite escribir, ejecutar y depurar pseudocódigo en un entorno amigable que visualiza el flujo de control y ayuda a corregir errores.

   - **Entorno de Programación:** Interfaz intuitiva que incluye herramientas para editar, ejecutar y depurar pseudocódigo, mejorando la comprensión de la lógica de programación.
