## Fundamento teórico

### 1.1. Componentes de un Sistema Informático

Un sistema informático se compone de dos elementos fundamentales: el **hardware** y el **software** , que trabajan conjuntamente para procesar, almacenar y comunicar información de manera eficiente y efectiva.

## a. Hardware

El hardware representa la parte física y tangible del sistema informático, incluyendo todos los dispositivos electrónicos y mecánicos que participan en el procesamiento de datos. Los componentes principales del hardware son:

- **Unidad Central de Procesamiento (CPU):** La CPU es conocida como el cerebro del ordenador, ya que es responsable de ejecutar instrucciones y procesar datos. Está compuesta por la Unidad de Control (CU) y la Unidad Aritmético-Lógica (ALU), que coordinan y realizan operaciones respectivamente (Stallings, 2018). La eficiencia de una CPU se mide por su velocidad de reloj y su arquitectura interna, aspectos que determinan el rendimiento general del sistema.

- **Memoria** : La memoria almacena datos e instrucciones necesarias para la ejecución de procesos. Se divide principalmente en:

   - **Memoria Principal (RAM):** Almacena temporalmente información que la CPU necesita acceder rápidamente. Es volátil, lo que significa que su contenido se pierde al apagar el sistema (Patterson & Hennessy, 2014).

   - **Memoria Secundaria** : Incluye dispositivos de almacenamiento como discos duros y unidades SSD, que retienen datos de forma permanente o hasta que sean modificados o eliminados por el usuario (Silberschatz, Galvin, & Gagne, 2018).

- **Dispositivos de Entrada/Salida (I/O)** : Estos dispositivos permiten la interacción entre el usuario y el sistema informático. Los dispositivos de entrada, como teclados y ratones, permiten introducir datos al sistema, mientras que los dispositivos de salida, como monitores e impresoras, presentan la información procesada al usuario (Tanenbaum & Bos, 2015).

- **Buses y Conectividad** : Los buses son canales de comunicación que transportan datos entre los diferentes componentes del hardware. La arquitectura y ancho de banda de estos buses afectan significativamente la velocidad y eficiencia de la transferencia de datos dentro del sistema (Stallings, 2018).

### 1.2. Tipos de Software

El software constituye la parte intangible del sistema informático, compuesto por programas y aplicaciones que instruyen al hardware sobre cómo realizar tareas específicas.

1. **Sistemas Operativos:** Actúan como una interfaz entre el usuario y el hardware, gestionando recursos y facilitando la ejecución de aplicaciones. Los sistemas operativos coordinan tareas como la asignación de memoria, administración de procesos y manejo de dispositivos I/O (Silberschatz et al., 2018).

2. **Software de Aplicación:** Incluye programas diseñados para realizar tareas específicas para el usuario, como procesadores de texto, navegadores web y programas de edición multimedia. Este tipo de software se construye sobre los servicios proporcionados por el sistema operativo (Sommerville, 2016).

3. **Software de Desarrollo:** Comprende herramientas utilizadas para crear otros programas, como compiladores, intérpretes y entornos de desarrollo integrado (IDE). Estas herramientas facilitan el proceso de escritura, depuración y mantenimiento de código fuente (Pressman & Maxim, 2015).

### 1.3. Sistemas Operativos y Gestión de Recursos

Los **sistemas operativos (SO)** son el núcleo del software en un sistema informático, responsables de gestionar y coordinar el uso eficiente de los recursos de hardware y software. Actúan como intermediarios entre el usuario y el hardware, proporcionando un entorno en el que las aplicaciones pueden ejecutarse de manera efectiva y segura (Silberschatz, Galvin, & Gagne, 2018).

### 2.2. **Actividad 2: Clasificación de componentes**

La clasificación de hardware se da según la función que realizan dentro o fuera de un computador, a seguir se detallan las funciones:

- **Procesamiento** : Tiene la capacidad de realizar operaciones lógicas, es decir, sus cálculos. Corresponde a la Unidad Central de Proceso (CPU), placa madre (motherboard).

- **Almacenamiento** : Permiten guardar la información, el principal componente de este tipo es la memoria de acceso aleatorio (RAM - sigla en inglés de Random Access Memory).

- **Entrada** : Permiten ingresar información al sistema. El teclado, el mouse, el micrófono y el escáner forman parte de este tipo de dispositivos.

- **Salida** : Permiten extraer información del sistema. Entre este tipo de dispositivos se encuentran la impresora y los altavoces.
