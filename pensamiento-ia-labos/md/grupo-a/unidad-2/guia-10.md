# ¿QUÉ SON ESTRUCTURAS SELECTIVAS?

Son mecanismos que permiten que un programa tome decisiones basadas en condiciones. Hay dos tipos principales:

## 1. Simples:

- **Definición:** Son aquellas que permiten que el programa elija una dirección de flujo basado en una única condición.

- **Uso Común:** Se utilizan cuando se necesita ejecutar una acción solo si una condición específica es verdadera.

- **Sintaxis Básica:**

## 2. Dobles:

- **Definición:** Son aquellas que permiten al programa elegir entre dos direcciones de flujo basadas en una condición.

- **Uso Común:** Se elige entre dos bloques de código dependiendo de si una condición es verdadera o falsa.

# ES IMPORTANTE CONOCER LOS OPERADORES:

Los operadores son símbolos o palabras clave que nos permiten comparar valores

- ( **operadores relacionales** ) o combinar condiciones **(operadores lógicos** ).

## 1. Relacionales:

Los operadores relacionales se usan para comparar valores. El resultado de

una comparación siempre será True ( **verdadero** ) o False **(falso** ).

|**Operador**|**Significado**|**Ejemplo en Python**|**Resultado**|
|---|---|---|---|
|==|Igual a|5 == 5|True|
|!=|Diferente de|5 != 3|True|
|>|Mayor que|7 > 3|True|
|<|Menor que|2 < 4|True|
|>=|Mayor o igual que|5 >= 5|True|
|<=|Menor o igual que|3 <= 5|True|

## 2. Lógicos:

Los operadores lógicos se utilizan para combinar varias condiciones en una sola evaluación. Son útiles cuando necesitas tomar decisiones más complejas.

|**Operador**|**Significado**|**Ejemplo en**|**Resultado**|
|---|---|---|---|
|||**Python**||
|and|Verdadero si ambas condiciones son verdaderas|(5 > 3) and (2 < 4)|True|
|or|Verdadero si al menos una condición es verdadera|(5 > 3) or (2 > 4)|True|

|not|Invierte el|valor|de|una|not (5 > 3)|True|
|---|---|---|---|---|---|---|
||condición||||||
